Version 26.2

Released October 31, 2025

This release introduces meaningful behavior changes. Please read carefully.

Functionality is aligned with Shot Clock procedures in the CSI Rule Book, with improved layout for everyday use. Examples show iPhone; iPad portrait matches that layout. Landscape on iPad uses the same controls with more screen space.

Screenshots show iOS 26. The Shot Clock runs on iOS 16 and up on iPhone and iPad — older OS versions may look different but behave the same.

Starting and restarting the timer

There is no separate Start button. Tap anywhere in the header to start or restart the timer — or enable Start Timer on Player Change so the timer restarts when you switch players.

On first load the timer shows zero. Tap the header to start; tap again to restart from the configured shot time (e.g. 30 seconds).

Important: Break still restarts from the Break Timer value (if set) and resets extension counters.

Example: For CSI league play, set Break Timer to the CSI Rule Book value (45 seconds) for the first shot after the break when that rule applies.

Break timer behaviour

If Break Timer is 0, Break does not restart the shot clock — it only resets extension counters. That matches CSI rules where the first shot after the break is not on the clock.

Important: Shot Timer and Extension sliders can also change Break Timer when you first configure. Be careful not to overwrite Break Timer when you only meant to change shot time.

Example one: Professional — Shot Timer / Extension 30s; Break Timer / Extension 60s.

Example two: BCA / USAPL — Shot Timer / Extension 45s; Break Timer / Extension 0s.

Break and Push

After Break, the Break control becomes Push. Push resets to the Break Timer value (if set) and switches player without resetting extension counters — for the case where the breaker pushes and the incoming player should get the same break clock.

Example: Professional match — Player 1 gets 60s on the break, then pushes; Player 2 also gets 60s (not the regular 30s shot).

Extra extension

Allows one additional extension beyond the usual one-per-rack limit — for CSI hill-hill final rack rules. The Extra Extension control appears in the toolbar when enabled in Config Detail.

Keeping score

Enable scoring in the configuration to show score controls in the Timer view. Tap a side to record a rack win; tap Set to begin a new set from the highest rack score.

Important: Scores and extensions can be edited in Player Manager.

Player Manager

Replace default Player 1 / Player 2 labels with real names, and adjust or reset extension counters and scores as needed.

Landscape mode (iPad)

iPad landscape rearranges timer controls to use the wider layout — especially helpful with larger Dynamic Type sizes.
